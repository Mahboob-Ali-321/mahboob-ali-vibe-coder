# Mahboob Ali: Vibe Coder

Create a bold, modern, dark-themed personal portfolio website for a frontend 
developer named Mahboob Ali.
BRAND IDENTITY:
- Tagline/vibe: "Vibe Coder" — a developer who builds fast, functional, and 
  aesthetically sharp digital products
- Color palette: deep dark background (near-black, #0A0A0F or similar), 
  with a vibrant accent color — electric blue, cyan, or purple gradient 
  (think cyberpunk/tech aesthetic, similar to modern SaaS/AI product sites)
- Typography: bold, modern sans-serif for headings (something like Space 
  Grotesk, Inter, or Sora), clean monospace accents for code-like details 
  (e.g., in the hero or skills section) to reinforce the developer identity
- Overall feel: confident, sharp, slightly futuristic — not corporate or 
  generic, this should feel like a builder's personal brand
SECTIONS TO INCLUDE:
1. HERO SECTION
   - Large, bold headline: "Hi, I'm Mahboob Ali" with an animated typing 
     effect or gradient text animation on a rotating subtitle: 
     "Frontend Developer", "Vibe Coder", "React Enthusiast", "UI Builder"
   - Short intro line: "I build clean, functional websites and web apps — 
     from AI tools to business sites — with React, Python, and a sharp eye 
     for design."
   - CTA buttons: "View My Work" (scrolls to projects) and "Let's Talk" 
     (scrolls to contact)
   - Subtle animated background: floating gradient blobs, particle effect, 
     or animated grid/mesh pattern (keep it tasteful, not distracting)
   - Social icons (GitHub, Instagram, WhatsApp) visible in hero or sticky nav
2. ABOUT SECTION
   - Brief personal narrative: passionate frontend developer who enjoys 
     building real products — from AI-powered tools to client websites for 
     small businesses
   - Emphasize hands-on, self-driven building style ("vibe coder" energy — 
     someone who ships fast and iterates)
   - Include a small stats/highlight row if it fits naturally (e.g., 
     "2+ Projects Shipped", "Full Stack Capable", "React & Python")
3. SKILLS SECTION
   - Visually interesting skill display (animated skill badges/pills, or 
     a grid of tech icons) for: React, JavaScript, Python, HTML, CSS, 
     Frontend Development, UI/UX Implementation
   - Use recognizable tech icons (React logo, Python logo, HTML5, CSS3 icons)
   - Add hover animations (glow, scale, or tilt effect) on each skill item
4. PROJECTS SECTION (this is the centerpiece — give it strong visual weight)
   - Project cards with a live preview screenshot/mockup, title, short 
     description, and a "View Live" button
   
   Project 1: ModelPulse
   - Description: "An AI model comparison dashboard that helps users find 
     the right AI model for their workload — clean data visualization and 
     an intuitive comparison interface."
   - Link: https://mahboobali.dpdns.org/
   
   Project 2: Smart Look Beauty Salon & Academy
   - Description: "A professional bridal studio website built for a real 
     salon client — showcasing services, bridal portfolio, academy courses, 
     and integrated booking/contact features."
   - Link: https://smart-look-bridal-studio.vercel.app/
   
   - Add hover effects on project cards (image zoom, gradient overlay reveal, 
     or lift/glow effect)
   - Include a "View on GitHub" link/icon per project if applicable, plus a 
     general link to full GitHub profile
5. GITHUB / CODE SECTION (optional but recommended)
   - A callout section: "Check out my code" with a button linking to:
     https://github.com/Mahboob-Ali-321
   - Could include a GitHub stats widget or contribution-style visual if 
     easy to implement, otherwise keep it simple with a strong CTA card
6. CONTACT SECTION
   - Headline: "Let's build something together"
   - WhatsApp button (primary CTA): links to 
     https://wa.me/916203778896?text=Hi Mahboob! I'd like to discuss a project.
   - Instagram link: https://www.instagram.com/cyb3r.aliiii__
   - GitHub link: https://github.com/Mahboob-Ali-321
   - Simple, elegant contact form (Name, Email/Phone, Message) as a 
     secondary option
   - Icons should have subtle hover animations (scale/glow)
7. FOOTER
   - Name/logo, quick nav links, social icons repeated
   - Small line: "Built with React & a lot of coffee" or similar personal touch
ANIMATIONS & INTERACTIONS (important — this should feel alive, not static):
- Smooth scroll-triggered fade-in/slide-up animations for each section as 
  the user scrolls
- Hero section: animated gradient text or typing effect for the rotating 
  subtitle
- Buttons: hover states with smooth scale/glow transitions
- Project cards: hover reveal effects (image scale, overlay with 
  description sliding up, or border glow)
- Skills section: subtle floating or pulse animation on icons
- Sticky navbar that shrinks/adds background blur on scroll
- Smooth scroll navigation between sections (clicking nav links scrolls 
  smoothly, not instant jump)
- Keep all animations fast and purposeful (200-500ms) — polished and 
  premium feeling, not overloaded or laggy
TECHNICAL REQUIREMENTS:
- Fully responsive (mobile-first, since most viewers will check on phone)
- Fast-loading, optimized images
- Dark mode as the only/default theme (no light mode toggle needed unless 
  you want to add one)
- SEO meta tags: "Mahboob Ali - Frontend Developer Portfolio", 
  "React Developer", "Web Developer Indore" (or relevant location if desired)
Overall goal: This should look like a premium, modern developer portfolio — 
confident, sharp, a little bold — the kind of site that itself acts as proof 
of skill. Every animation and interaction should reinforce that this person 
knows how to build polished, professional web experiences.
